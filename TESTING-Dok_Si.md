# Данные Dok_Si

Скин автора для credits загружается по нику `Dok_Si` через Minecraft-профиль, поэтому отдельный PNG-файл для обычного лицензионного скина не требуется.

Чтобы передать точные настройки автора для отображения в credits и для тестовой базовой конфигурации, положите/передайте файл:

`config/FemaleGenderMod/nick_Dok_Si.json`

Можно просто загрузить этот JSON в чат. В нём находятся значения профиля, включая размер, форму, положение, физику и звуки. Мод уже умеет читать этот файл для манекена `Dok_Si`.
