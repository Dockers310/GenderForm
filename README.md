# GenderForm — Fabric 26.2

Это отдельная версия GenderForm только для **Fabric + Minecraft 26.2**. Других игровых версий и загрузчиков в архиве нет.

## Что изменено

- профиль игрока для синхронизации привязан только к нику; Mojang UUID аккаунта не используется как идентификатор профиля;
- online-mode и offline-mode серверы используют одну и ту же nickname-схему;
- настройки сохраняются в `nick_<ник>.json`; при наличии старого `<UUID>.json` выполняется попытка миграции;
- добавлена форма груди `Стандартная` / `Округлая`;
- округлая форма использует отдельную 3D-геометрию со сглаженными нормалями;
- выбранная форма входит в обычный sync-пакет и поэтому может быть передана серверным мостом;
- Fabric-клиент принимает play-phase sync и от сервера с модом, и от Paper/Folia-плагина без обязательного configuration-phase hello;
- cloud/account-UUID загрузка профиля отключена для PlayerConfig.

## Сборка

Нужен **JDK 25**. Для этого архива используется Gradle Wrapper.

```powershell
.\gradlew :fabric:26.2:build
```

Готовый Fabric jar ищи в каталоге `fabric/versions/26.2/build/libs/`.

### Важно для сборки

Это целевая сборка только для Fabric 26.2. В проекте сохранён `common` слой оригинального GenderForm, потому что он содержит общие классы мода и используется системой сборки для подготовки Minecraft mappings. Поэтому в логе Gradle может появляться задача `:common:26.2:createMinecraftArtifacts` и компонент NeoForm; это не означает, что внутри итогового мода присутствует NeoForge.

Сборка: `./gradlew build`

### Только Fabric 26.2

Этот архив содержит одну целевую ветку Minecraft: Fabric 26.2. NeoForge-модуль удалён из дерева проекта. `common` остаётся частью исходной архитектуры GenderForm и используется для общих классов и подготовки Minecraft mappings; это не означает, что итоговый JAR является NeoForge-модом.

Основная команда сборки:

```powershell
.\gradlew build
```

Можно также собрать только Fabric-проект:

```powershell
.\gradlew :fabric:26.2:build
```


> Это наша переделанная версия проекта. Технический `mod_id` сохранён как `female_gender_mod` для совместимости с ресурсами и существующими настройками.


### Итоговый JAR
После `./gradlew clean build` runtime/remapped JAR называется `GenderForm.jar`.


### Сборка Fabric 26.2

Запускай из корня проекта:

```powershell
.\gradlew clean build
```

Корневая задача `build` специально запускает `:fabric:26.2:build`, поэтому после успешной сборки должен появиться итоговый JAR `GenderForm.jar` в `fabric/26.2/build/libs/`.
